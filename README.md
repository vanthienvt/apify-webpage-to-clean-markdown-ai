# Webpage to Clean Markdown & RAG Chunks Extractor for LLMs

Transforms any public webpage, documentation article, or blog post into **clean, noise-free Markdown** and pre-split **Retrieval-Augmented Generation (RAG) text chunks** ready for OpenAI, Claude, Gemini, LangChain, and LlamaIndex pipelines.

## Key Capabilities
- Strips scripts, styles, navigation bars, and footer clutter automatically.
- Preserves semantic heading structure (`# H1`, `## H2`, `### H3`) and bullet lists.
- Calculates `wordCount` and `estimatedTokens` so AI engineers can budget context windows accurately.
